# Legacy native prototype — не является целевой версией

Этот каталог содержит ранний экспериментальный прототип с самостоятельно написанными механиками и графикой. Он **не соответствует требованию точного переноса оригинальной игры** и больше не используется как основная версия.

## Целевая Android-сборка

Основная работа ведётся с оригинальным файлом `original/prehistoric-tribes-0.1.38.jar`. Android APK собирается workflow `.github/workflows/build-android.yml`: оригинальная игра и её ресурсы встраиваются в отдельное приложение, а сенсорный ввод добавляется на уровне игрового класса.

Сохраняются оригинальные игровые данные, правила, графика, карты, миссии, интерфейс и звук. Изменяется только способ ввода:
- касание поля выбирает/подтверждает действие в соответствующей клетке;
- свайпы заменяют кнопки направления;
- удержание открывает оригинальное меню;
- нижние левый и правый углы вызывают оригинальные soft-key команды;
- экран запускается в альбомной ориентации без виртуальной клавиатуры.

Каталог оставлен для истории экспериментов, но новые игровые механики и графика сюда не добавляются.
